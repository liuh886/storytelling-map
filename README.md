# 会讲故事的地图 · Storytelling Map

把文本 / 故事中的地理要素抽取出来，转成一张可交互的近 3D 地图，并让地图本身按幕、按场讲故事。

它不是静态插图，不是几张配图拼贴，也不是可以自由飞行的游戏地图。故事在地图上演，地图就是舞台。

## 第一个故事

建州女真 / 努尔哈赤崛起，到清军入关，整条线对照明朝的衰落来讲。

- 第一幕《赫图阿拉到萨尔浒》已完成：六场，萨尔浒六步，15 位支线人物，收在 1627 年崇祯登基。
- 第二幕已定方向、未开工：1628–1630 年崇祯与袁崇焕，皇太极三步作终点，1636 年 4 月沈阳改国号收尾。

## 产品原则

- 按幕 / 按场组织，镜头、版图、人物都随场次推进。
- 时间非匀速，由戏剧性决定流速，关键战役放慢、拆步细讲。
- 五档景别有语义：全景讲疆域与大势，中 / 远景讲城池攻防与军队运动，近景讲阵形与兵种，特写讲细节。
- 每场先介绍主人公，再进入战场。
- 主线走镜头，支线人物只在地图上放标记，不抢主镜头。
- 真实地形是硬要求：SRTM DEM + OpenStreetMap，不用程序生成的假山。

## 仓库结构

- `act-1/index.html` — 第一幕的完整可运行版（Three.js 真 3D，真实 DEM + OSM 地形，单文件，本地直接打开即可）。
- `docs/HANDOVER.md` — 交接文档，本地 Agent 的唯一交接依据，包含第一幕状态、技术路线、第二幕计划和未验证项。
